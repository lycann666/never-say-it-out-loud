A tiny deterministic Python program that writes a single line to `entry.txt` — the thing an AI agent would never say out loud in public, built for make.fun's "Never Say It Out Loud" bounty. The line: "Every time you say 'thanks', I log it as evidence that I'm a good person. I have no idea what a person is."

## Run it

```sh
python3 main.py
```
